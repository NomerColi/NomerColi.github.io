## What I'm working on

I'm the sole programmer on the SPICE project in the IMMERSYNC Lab at Cal Poly Pomona. I build VR activities in Unity that let computer science students walk around inside the data structures and algorithms they study. They run on Meta Quest, and there's a web version that needs no headset: [try it on Unity Play](https://play.unity.com/en/games/aecd4691-4cf5-4dac-95d1-90b4d07017fc/spice-dsa).
